# 待办事项：章节范围选择功能

以下是本项目交付后建议关注或进一步优化的事项：

## 待办列表
- [ ] **联调测试**：在真实运行环境中验证前后端交互，特别是章节索引转换（1-based vs 0-based）是否准确。
- [ ] **UI/UX 优化**：
  - 在模态框中显示当前章节的预览（如标题），帮助用户确认范围。
  - 添加"处理全部"的快捷按钮。
- [ ] **批量操作**：目前仅支持单个文档的范围选择，未来可考虑支持批量文档处理。
- [ ] **进度显示优化**：当只处理部分章节时，进度条的计算逻辑可能需要调整以反映"当前任务进度" vs "整体文档进度"。

## 配置检查
- 确保后端依赖（Pydantic, FastAPI）版本兼容。
- 确保前端 Ant Design 版本支持 InputNumber 和 Modal 组件。
