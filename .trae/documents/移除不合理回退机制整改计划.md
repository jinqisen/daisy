# 回退机制整改计划 (Comprehensive Cleanup)

## 目标
移除 8 项工程上不成熟的“隐式回退”逻辑，强化系统确定性，防止配置错误导致的静默劣化。

## 1. Config & Environment 模块
- **目标文件**: [config.py](file:///Volumes/My%20PSSD/Daisy_Demo/Daisy_server/app/core/config.py)
- **动作**:
  - 移除 `set_huawei_search_api_key` 中 `MAAS_API_KEY` 的自动填充。
  - 移除 `_model_dir` 的多级路径猜测，仅保留 `TARGET_MODEL_DIR` 环境变量和单一默认路径。

## 2. LLM & Memory Service 模块
- **目标文件**: [llm.py](file:///Volumes/My%20PSSD/Daisy_Demo/Daisy_server/app/services/llm.py)
  - 移除 `get_llm` 中当 Provider 配置无效时自动 `Falling back to default` 的逻辑。
  - 移除 `get_llm` 末尾对 `os.getenv` 的额外读取（Last Resort）。
- **目标文件**: [memory.py](file:///Volumes/My%20PSSD/Daisy_Demo/Daisy_server/app/services/memory.py)
  - 移除 `MemoryService.__init__` 中 Provider 配置无效时的 Fallback，改为抛出 `ValueError`。防止向量空间不匹配。

## 3. Tools 模块
- **目标文件**: [tools.py](file:///Volumes/My%20PSSD/Daisy_Demo/Daisy_server/app/core/tools.py)
  - 移除 `SearchTool.run` 中的 Mock 数据分支。无 Key 时抛出 `ConfigurationError`。

## 4. Prompt Loader 模块
- **目标文件**: [prompt_loader.py](file:///Volumes/My%20PSSD/Daisy_Demo/Daisy_server/app/core/prompt_loader.py)
  - 移除 `_find_prompts_dir` 中的 Legacy 相对路径回溯。
  - 修改 `render` 方法：发生异常时直接 `raise`，不再返回 "Error: ..." 字符串。

## 验证
- 确认所有修改点在配置缺失时均能明确报错。
- 确认合理的高可用回退（Redis/Session）未受影响。
