# CONSENSUS: 增加节假日感知能力

## 1. 最终需求描述
在 `Daisy_server` 中增加节日识别模块，并在生成回复时注入节日上下文。

## 2. 技术实现方案
### 2.1 新增文件
- `app/core/holidays.py`: 包含 `get_holiday_info(date)` 函数。

### 2.2 节日数据源
- **公历**: 字典匹配 `MM-DD`。
- **农历**: 字典匹配 `YYYY-MM-DD` (预置 2024-2026)。

### 2.3 修改文件
- `app/workflow/nodes/generation.py`: 调用 `get_holiday_info` 并更新 Prompt。

## 3. 验收标准
- **Case 1**: 2024-12-25 -> 圣诞节。
- **Case 2**: 2025-01-29 -> 春节。
- **Case 3**: 2024-05-20 -> 520情人节。
- **Prompt**: 包含 `今天是 **圣诞节**。`

## 4. 风险评估
- **农历过期**: 需要定期更新农历表（目前覆盖到2026年，足够短期使用）。
