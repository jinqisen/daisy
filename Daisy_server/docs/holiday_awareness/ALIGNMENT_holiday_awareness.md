# ALIGNMENT: 增加节假日感知能力

## 1. 原始需求
用户希望AI在回复时能感知当前的节日（如春节、情人节、圣诞节），并进行相应的互动（如节日祝福）。

## 2. 需求理解与分析
### 2.1 核心痛点
- AI 目前只知道时间（几点），不知道日期对应的特殊意义。
- 缺少节日氛围感：例如在圣诞节，AI 应该主动祝用户圣诞快乐，或者聊相关话题。

### 2.2 现有架构分析
- **生成节点**: `app/workflow/nodes/generation.py`。
- **缺失环节**: 缺乏日期到节日的映射逻辑。

### 2.3 拟定解决方案
- **节日识别模块**: 创建 `app/core/holidays.py`，负责根据日期判断是否是节日。
- **支持范围**:
    - **公历节日**: 元旦、情人节、妇女节、愚人节、劳动节、青年节、儿童节、建党节、建军节、教师节、国庆节、万圣节、平安夜、圣诞节。
    - **特殊日期**: 520 (5月20日)。
    - **农历节日 (近期硬编码)**: 考虑到不引入新依赖，将内置 2024-2026 年的主要农历节日（春节、元宵、端午、七夕、中秋、重阳、除夕）。
- **Prompt 增强**:
    - 在 `Context` 中显示：`当前日期：YYYY-MM-DD (星期X) [节日名称]`。
    - 在 `Constraint` 中增加：`今天是 **[节日名称]**。请在回复中自然地融入节日氛围（如祝福、询问过节计划），但不要生硬重复。`

## 3. 决策策略
- **无新依赖**: 采用“公历算法 + 农历查表”的方式，避免引入 `lunar-python` 等外部库，保持项目轻量。
- **可扩展性**: 节日表独立存放，方便后续更新。

## 4. 验收标准
1.  **节日识别**: 输入 12月25日，识别为“圣诞节”。
2.  **Prompt 注入**: 生成的 Prompt 包含节日信息和相关约束。
3.  **农历支持**: 输入 2025年1月29日，识别为“春节”。
