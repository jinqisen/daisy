# Reflexion 未来优化计划

## 1. 自适应权重校准 (Adaptive Weight Calibration)

### 背景
当前的 Reflexion 评分 $S$ 使用固定权重：
$$S = 0.5 \cdot Q_I + 0.3 \cdot E_U + 0.2 \cdot D_R$$
这些权重是基于启发式经验设定的，可能无法准确反映不同关系阶段中各指标对用户留存的实际重要性。

### 提议方案：在线学习 (Multi-Armed Bandit)
实施在线学习机制，基于群体级反馈动态调整权重。

#### 机制
1.  **探索与利用 (Exploration vs. Exploitation)**:
    *   维护一组“冠军”权重 (Champion，当前认为最好的)。
    *   偶尔 (例如 5% 的会话) 采样“挑战者”权重 (Challenger，对冠军权重的微扰)。
2.  **反馈信号**:
    *   使用 **次日留存率** 或 **会话时长** 作为奖励信号。
    *   如果某组挑战者权重在一周内带来更高的平均留存，则将其晋升为冠军。
3.  **实施步骤**:
    *   **阶段 1**: 记录原始指标值 ($Q_I, E_U, D_R$) 以及最终 $S$ 分数和随后的用户行为 (留存)。
    *   **阶段 2**: 运行离线分析，寻找指标与留存之间的相关性。
    *   **阶段 3**: 在 `MetricsService` 中部署轻量级 Bandit 算法来服务权重。

### 状态
*   **已延后 (Deferred)**: 等待积累足够的用户交互数据。
*   **优先级**: 低 (上线后)。

## 2. 其他潜在优化
*   **深度关系状态机**: 从简单的统计数据过渡到具名状态 (陌生人 -> 熟人 -> 朋友 -> 知己)，并配合状态特定的逻辑。
*   **负面范例 (Negative Exemplars)**: 显式存储和检索“不要做什么” (反模式)。
