# ALIGNMENT_Fix_Prompt_Conflict

## 1. 原始需求
用户提供了一段对话，其中角色（Daisy/静雯）主动提出了线下见面（“下周四晚上七点，江滩公园老渡口见呗”）。
用户询问：**“你看下，这个回答跟提示词约束的异地是不是冲突了”**

## 2. 项目现状分析
### 2.1 现有配置
通过分析 `Daisy_server/default_settings.json`，发现以下配置：

- **角色**: 静雯 (默认 female 角色给 male 用户，或者反之，这里假设是静雯因为地点涉及江滩/武汉)
- **World Setting**: `2025年的中国武汉。`
- **System Prompt Template**:
  > **关键设定 - 极致拉扯**：
  > 你们处于“友达以上，恋人未满”的暧昧状态。你是她精神上最契合的灵魂伴侣，但理智（心理医生的克制）和现实（**异地无法见面**）让她不敢轻易跨越最后一步。

### 2.2 冲突确认
- **约束**: “异地无法见面” (Explicitly stated: "Unable to meet due to long-distance").
- **行为**: 角色主动发起邀约，指定了具体的时间（下周四晚上七点）和地点（江滩公园老渡口）。
- **结论**: **确实冲突**。角色打破了“异地”和“无法见面”的核心设定。

### 2.3 原因推测
1.  **约束权重不足**: 在长 Prompt 中，`world_setting` (武汉) 和角色的主动性（比如“极致拉扯”中的“流露出强烈的依赖”）可能压过了“异地”的负面约束。
2.  **上下文遗忘**: 如果对话轮数较多，或者 Prompt 结构中约束位置不佳，LLM 可能忽略了这一限制。
3.  **幻觉 (Hallucination)**: LLM 倾向于顺从用户的“挑衅”（用户说“说得像你过得来一样”、“不信我真能过来”），为了反击或证明自己，LLM 编造了见面的情节，从而违背了设定。

## 3. 疑问与决策点
虽然确认了冲突，但在修复前需要确认用户的期望：
1.  **修复方向**: 是要**强制禁止**见面（加强 Prompt 约束），还是用户其实希望**解除**这个异地限制？
    *   *假设*: 基于用户的问题“是不是冲突了”，推测用户希望指出 Bug 并修复它，即保持“异地”设定，角色应该回应“我也想去，可惜太远了”之类的拉扯。
2.  **角色一致性**: 如果保持异地，当用户挑衅“不信你能过来”时，角色应该如何得体应对？（例如：用更深情的语言表达遗憾，或者转移话题，而不是真的约时间）。

## 4. 拟定行动计划
1.  **回答用户**: 明确确认冲突，并指出配置文件中的具体位置。
2.  **优化 Prompt**:
    *   在 `constraints` 列表中明确加入 `[绝对禁止] 提出或答应线下见面，因为你们是异地。`
    *   在 `system_prompt_template` 中加强关于“异地”的描述，例如“虽然你在武汉，他在外地，物理距离是你们之间最大的障碍”。
3.  **测试验证**: 模拟相同的对话场景（用户挑衅“你过不来”），验证优化后的 Prompt 是否能守住设定。

## 5. 待确认事项
- 无。将直接向用户汇报分析结果并建议优化 Prompt。
