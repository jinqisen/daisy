
### 途径四：豆瓣多轮对话语料 (E:\Daisy\TrainMode)
您项目中包含了一个大规模的豆瓣对话数据集 (`DoubanConversaionCorpus`)。

- **数据特点**: 极其口语化、话题广泛（包含生活、情感、闲聊）、噪声较大。
- **适用性**:
    - **适合**: 增强模型的“闲聊能力”和“中文口语理解能力”。
    - **不适合**: 直接用于训练专业心理咨询能力（因为包含大量无关话题如租房、买东西等）。
- **处理策略**:
    1. **筛选**: 只提取 `Label=1` (正样本) 的数据。
    2. **清洗**: 豆瓣数据是分词后的（如 "我 爱 你"），需要合并为自然句子。
    3. **过滤**: 强烈建议使用关键词（如 "难过", "情感", "心情" 等）进行过滤，只保留情感相关的对话。
    4. **配比**: 建议作为辅助数据，占比不超过总训练数据的 20%-30%，避免模型染上“网友味”。

**转换工具**:
我为您编写了专用转换脚本 `scripts/convert_douban_to_sharegpt.py`，它会自动执行上述清洗和过滤步骤。

```powershell
python scripts/convert_douban_to_sharegpt.py
```
产出文件: `data_export/douban_sharegpt.jsonl`
