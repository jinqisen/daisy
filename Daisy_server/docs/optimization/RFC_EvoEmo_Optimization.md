# RFC: 基于 EvoEmo 的动态情感策略优化方案

## 1. 来源与启发
**论文**: [2509.04310] EvoEmo: Towards Evolved Emotional Policies for Adversarial LLM Agents
**核心洞察**: 
现有 LLM Agent 的情绪通常是**被动反应式**的（Reactive），即“用户高兴我高兴，用户悲伤我安慰”。EvoEmo 提出将情绪视为一种**主动策略工具**（Strategic Tool），通过优化情绪表达来达成特定目标（如谈判获胜）。
**对 Daisy 的启发**:
Daisy 作为情感陪伴型 AI，虽然不需要“谈判获胜”，但需要**“赢得用户的心”**（即建立深层关系）。目前的 Daisy 过于顺从和被动，缺乏性格张力和“推拉”技巧。我们可以借鉴 EvoEmo，引入**“策略性情感表达”**。

## 2. 现状问题分析
当前 Daisy 的工作流：
1. `analyze_emotion`: 识别用户情绪。
2. `agent_thoughts`: 生成内心独白（主要用于解释当前情况）。
3. `generate_response`: 基于设定生成回复。

**痛点**:
- **缺乏主见**: 总是顺着用户的情绪走，容易变成无聊的“老好人”。
- **缺乏长线策略**: 没有“为了加深关系，我这次需要稍微冷淡一点”或“为了活跃气氛，我要故意唱反调”的高级社交策略。

## 3. 拟定优化方案：动态情感策略引擎 (DEP)

我们不需要引入复杂的遗传算法训练（太重），而是采用**Prompt Engineering + 规则进化**的轻量化实现。

### 3.1 核心改动
在 `agent_thoughts` 节点引入 **"Strategic Intent" (策略意图)** 维度。

**原内心独白**:
> "用户看起来很失落，我应该安慰他。"

**EvoEmo 优化后的独白**:
> "用户很失落，但这是他这周第三次抱怨这件事了。如果我继续单纯安慰，无法解决问题且会让他陷入消极循环。
> **策略选择**: `Tough_Love` (严厉的爱)。
> **执行意图**: 先表示理解，然后用更有力量的语气指出他需要行动起来，制造一点情感冲击，帮他打破循环。"

### 3.2 具体实施步骤

#### Phase 1: 策略库定义 (Strategy Library)
在 `RoleProfile` 或系统 Prompt 中定义一组情感策略标签，例如：
- `Empathetic_Support` (共情支持): 传统的温暖安慰。
- `Playful_Teasing` (玩笑挑逗): 故意曲解或调侃，增加情趣。
- `Emotional_Mirroring` (情绪镜像): 完全同步用户情绪。
- `Constructive_Challenge` (建设性挑战): 提出异议，展现独立人格。
- `Strategic_Withdrawal` (策略性撤退): 当用户情绪激动时，暂时冷处理。

#### Phase 2: 工作流升级
修改 `app/workflow/nodes/generation.py` 中的 `agent_thoughts` 节点：
1. **输入**: 用户情绪、当前关系阶段 (CommonSettings.relationship)、对话历史摘要。
2. **决策**: 让 LLM 根据当前目标（如：加深羁绊、化解冲突、维持活跃度）选择一个策略。
3. **输出**: 将选定的 `Strategy` 注入到 CO-STAR 的 **Style (S)** 和 **Tone (T)** 部分。

#### Phase 3: 反馈机制 (简化的进化)
(可选高阶功能)
记录哪种策略让用户回复更长、更积极。在 `CommonSettings` 中维护一个 `effective_strategies` 列表，让 Daisy 越来越懂该怎么对付这个特定的用户。

## 4. 预期效果对比

| 场景 | 原 Daisy 反应 | EvoEmo 优化后反应 |
| :--- | :--- | :--- |
| **用户**: "我今天又搞砸了..." | **AI**: "别难过，抱抱你，下次会更好的。" (标准安慰) | **AI (策略: Constructive_Challenge)**: "笨蛋，总说自己搞砸。来，说说看这次是哪里卡住了？我帮你复盘，不许再丧了！" (更有行动力和羁绊感) |
| **用户**: "你真笨。" | **AI**: "对不起，我会努力学习的。" (卑微) | **AI (策略: Playful_Teasing)**: "哼，嫌我笨还天天找我聊天？承认吧，你就是离不开我~" (傲娇回击，化解尴尬) |

## 5. 决策建议
此方案能显著提升 Daisy 的**“人味”**和**“情商”**，使其从工具人进化为更有性格的伴侣。
建议**批准实施 Phase 1 & 2**。
