# ALIGNMENT: 增强AI回复的时间感知能力

## 1. 原始需求
用户希望AI在回复时能感知当前的客观时间，并根据时间调整回复的内容和建议。
例如：用户在半夜聊天时，AI不应建议喝茶或进行不符合该时间段的活动。

## 2. 需求理解与分析
### 2.1 核心痛点
- AI目前缺乏“当前时间”的上下文。
- AI生成的建议（如“喝杯咖啡提神”）可能在深夜等特定时间段显得不合时宜，破坏沉浸感。
- 缺乏基于时间的语气调整（如深夜应更温柔，白天更活跃）。

### 2.2 现有架构分析
- **生成节点**: `app/workflow/nodes/generation.py` 中的 `generate_response` 和 `_generate_costar_instruction` 是核心。
- **Prompt构建**: 目前使用 CO-STAR 框架，包含 Context, Objective, Style, Tone, Audience, Response。
- **缺失环节**: Prompt 中未包含当前时间信息。

### 2.3 拟定解决方案
- **注入时间**: 在 `_generate_costar_instruction` 中获取当前系统时间。
- **Prompt增强**:
    - 在 `Context` 或 `Constraint Layer` 中加入时间信息。
    - 增加具体指令，要求AI的行为建议必须符合当前时间常识。
    - 要求AI的语气与时间氛围匹配。

## 3. 疑问与澄清
- **时间源**: 使用服务器当前时间即可（假设用户与服务器在同一时区，或暂不考虑多时区复杂性，默认为服务器本地时间）。
- **格式**: 24小时制，并附带自然语言描述（如“深夜”、“清晨”）。

## 4. 决策策略
- **实现方式**: 修改 `app/workflow/nodes/generation.py`。
- **无需数据库变更**: 这是一个纯逻辑/Prompt层面的修改。

## 5. 验收标准
1.  **时间感知**: AI明确知道当前是几点。
2.  **行为合理性**: 在深夜（如23:00-05:00）测试，AI不应建议喝咖啡/剧烈运动，应建议休息/助眠。
3.  **语气适配**: 深夜回复语气应较平时更平和。
