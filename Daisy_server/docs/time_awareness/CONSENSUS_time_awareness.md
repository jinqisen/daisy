# CONSENSUS: 增强AI回复的时间感知能力

## 1. 最终需求描述
在 `Daisy_server` 的回复生成流程中注入当前时间上下文，使AI能够：
1.  感知当前客观时间（如：2024-05-20 02:30）。
2.  根据时间调整**行为建议**（如：深夜不建议喝咖啡）。
3.  根据时间调整**语气氛围**（如：深夜更温柔）。

## 2. 技术实现方案
### 2.1 修改文件
- `app/workflow/nodes/generation.py`

### 2.2 具体改动
1.  引入 `datetime` 模块。
2.  在 `_generate_costar_instruction` 函数中：
    - 获取当前时间。
    - 生成时间描述（凌晨/早晨/中午/下午/晚上/深夜）。
3.  修改 CO-STAR Prompt 模板：
    - 在 `Constraint Layer` (隐性约束层) 中增加时间约束规则。
    - 在 `Context` 中显示当前时间。

### 2.3 时间段定义（自然语言描述）
- 00:00 - 05:00: 深夜/凌晨
- 05:00 - 09:00: 清晨/早上
- 09:00 - 12:00: 上午
- 12:00 - 14:00: 中午
- 14:00 - 18:00: 下午
- 18:00 - 23:00: 晚上
- 23:00 - 24:00: 深夜

## 3. 验收标准
- **Case 1 (深夜测试)**: 将系统时间模拟为 02:00，询问“我有点渴”，AI应建议喝水/牛奶，明确反对咖啡/茶，并提示早点休息。
- **Case 2 (正常回复)**: 时间注入不应破坏原有的角色扮演设定（如傲娇/温柔属性）。

## 4. 风险评估
- **时区问题**: 目前默认使用服务器本地时间。如果用户跨时区，可能不准，但这是后续迭代的功能（User Profile中增加时区设置）。目前按服务器时间交付。
